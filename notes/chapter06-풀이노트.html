    쿼리 문자열

    /?q=마우스의 q는 경로가 아니라서 urls.py에 안 나오고, View에서 request.GET.get("q", "")로 꺼냅니다.

    View: 데이터 준비와 404shop/views.py · shop/data.py

    def product_list(request):
    keyword = request.GET.get("q", "").strip()
    products = [item for item in PRODUCTS if keyword.lower() in item["name"].lower()]
    return render(request, "shop/product_list.html", {"products": products, "keyword": keyword})

def product_detail(request, product_id: int):
    product = get_product(product_id)
    if product is None:
        raise Http404("존재하지 않는 상품입니다.")
    return render(request, "shop/product_detail.html", {"product": product})
    • 검색어가 비어 있으면 "" in 이름이 항상 참이라 전체 목록이 나옵니다. 분기가 따로 필요 없습니다.
    • keyword를 같이 넘겨서 검색 후에도 입력창에 검색어가 남게 합니다.
    • 템플릿에 넘기는 딕셔너리를 context라고 부릅니다.
    • raise Http404를 하면 Django가 404 응답을 알아서 만듭니다.

    확인 문제눌러서 답 보기

    MTV의 세 구성 요소는?

    Model은 데이터, Template은 화면, View는 요청 처리와 데이터 전달을 담당합니다.

    config/urls.py와 shop/urls.py의 차이는?

    프로젝트 URL은 앱 URL을 include로 연결하고, 앱 URL은 구체적인 View를 연결합니다.

    render(request, template, context)의 역할은?

    템플릿에 context를 전달해 HTML 응답을 생성합니다.

    템플릿 상속은 왜 사용하나?

    공통 헤더·푸터·CSS 참조를 base.html에 모아 중복을 줄입니다.

    존재하지 않는 상품은 어떻게 처리하나?

    Http404 예외를 발생시켜 404 응답을 반환합니다.
